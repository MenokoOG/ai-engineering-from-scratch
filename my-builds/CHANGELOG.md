# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-07-25

### Added

- Phase 1 (Math Foundations): all 22 lesson projects built from scratch in Python; every `project.py` runs standalone and self-verifies against numpy/sklearn.
- TypeScript builds for lessons 01 (vectors), 05 (autodiff engine), 14 (norms/distances), 19 (complex numbers), 21 (graphs).
- `LESSON.md` per lesson: project summary, main points learned, plain-English algorithm explanations.
- `FEEDBACK.md` per lesson: verified errors and bugs found in the course's own code, docs, and quizzes.
- `CHEATSHEET.md`: master reference of all Phase 1 algorithms, patterns, key numbers, and gotchas.
